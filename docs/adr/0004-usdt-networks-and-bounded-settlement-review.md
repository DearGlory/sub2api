# USDT 采用共享经营规则的多网络选择及有界人工入账恢复

用户明确要求首版支持多个 USDT 网络由付款人选择，而不是只开放单网络或在负载均衡时暗中切链。各网络共享 USD 订单计价、本站充值到账倍率与本站手续费；网关换算和用户实际链上费用不混入本站倍率。管理员需要能配置可用网络，但网关是否能锁定网络、如何映射切换产生的子订单，仍由协议证据及合同测试验证，不能从缺少 network 的回调中声称独立证明链网络。

USDT 的入账宽限期默认为 30 分钟并允许后台调整，从原订单付款有效期结束或用户取消时刻中的较早者起算。每张订单保存自己的截止基准和规则；通知重发、后台活动或后续配置调整不得延长旧订单宽限期。此规则仅适用于新增 USDT，既有支付服务商的取消与过期规则不修改。

超过宽限期的已验证款项进入支付订单管理的待人工核对流程。管理员只有在签名、商户、订单、交易及金额证据已通过时，才可带备注确认按原单额度入账；确认必须幂等且不接受自由输入新的入账金额。无效或不匹配证据不能通过人工按钮绕过验证。拒绝自动／人工入账不等于执行退款，退款仍由运营在系统外核对处理。

选择这一边界意味着本站需要新增显式的审核状态、受控确认动作与审计，而不是仅写一条日志或让运营脱离原订单直接加钱。这比沿用现有取消可恢复、过期短窗口的隐含规则更明确，代价是要验证新的并发确认与状态转换。只有业务验收通过后才可启用；当前记录决定，不代表代码已实现。
