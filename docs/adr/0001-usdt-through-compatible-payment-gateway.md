# USDT 通过兼容支付网关接入，不在本项目托管钱包

本次 USDT 充值采用来源项目所体现的 EPUSDT／GMPay 兼容网关路线，并接入目标项目现有的充值订单与入账流程。用户在第一轮访谈明确选择兼容网关模式，而非直接自建链上收款；因此本次范围不包含链上监听、收款地址分配或私钥托管。

这一选择保留了现有订单体系，也把链上收款能力交由接入网关提供，代价是必须依赖具体网关的协议与可用性。不能仅凭“EPUSDT”名称就认定任意同名服务兼容；实际服务的下单、查单、签名、金额与回调契约仍需验证。商户接入参数通过现有支付服务商实例配置管理，不复制来源项目作者的商户地址或推广链接作为生产接入。

本 ADR 接受的是接入路线，不代表整体验收方案、具体网关或生产部署已获批准。外部综合充值页的身份传递、余额入账协议，以及 USDT 的退款与迟到付款行为仍待后续访谈确认。
