# 多网络 USDT 的用户选择不等于网关锁网

用户确认首版需要支持多个 USDT 网络并由用户显式选择。固定版本的 GMwalletApp/epusdt 协议核查显示，用户选网后收银台仍可调用切换接口改变资产或网络；切换目标可能创建子单，最终成功通知通常归并到父单，通知字段没有 network。

本站因此保存 `requested_network` 作为用户和订单的选择记录，不把它命名为 `settled_network`，也不声称普通签名回调独立证明了实际链网络。自动入账可以验证 USDT 资产、商户、订单、金额和交易去重证据；网络一致性只有在网关禁用切换、回调增加网络字段或真实端到端验证之后才能作为自动规则。

在这些条件没有满足前，网络敏感场景进入人工核对；本地配置网络列表不会强行改变第三方收银台行为。这个边界保留了多网络入口，同时避免把缺失的协议证据误报成链网络已确认。
